How to read this — measured vs estimated

DeepSeek cost = MEASURED by account-balance delta (reliable). DeepSeek tokens = ESTIMATED (its Anthropic-compat endpoint under-reports usage). Claude = token counts from each subagent's completion notification: r3 spot-check EXACT; r1/r2 frontier judging ESTIMATED (not logged to file at the time). Going forward both are logged precisely.

measured = a real, logged number. est = an estimate (DeepSeek token counts are derived from cost, because its endpoint under-reports usage; some early Claude judging wasn't logged to file).
